# MUSE PORTAL Frontend

A modern React-based frontend for the **MUSE PORTAL** project.  
This repository contains the user interface for an academic portal experience with a clean, responsive, and visually polished layout.

## Features

- Built with **React**
- Fast development workflow with **Vite**
- Responsive UI for desktop and mobile
- Modular component structure
- Easy to extend for new pages and features
- Clean codebase for campus/portal-style applications

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Ayush-M2488/MUSE_PORTAL-Frontend.git
cd MUSE_PORTAL-Frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The app will usually run at:

```bash
http://localhost:5173
```

## Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
